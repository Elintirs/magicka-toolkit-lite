# Magicka Toolkit Lite

Чистая версия патча: **только журнал и мониторинг** плюс открытие DLC и роб. Никаких читов — ни авто-защиты,
ни лечения, ни техник, ни песочницы, ни арены, ни редактора. Эти перехваты в этой сборке даже не ставятся, и
включить их из `settings.ini` нельзя.

## Что умеет

| Раздел (F2) | Что делает |
|---|---|
| **Журнал** | журнал боя этой игры: каждый удар по тебе, статусы, смерти и разбор смерти, смены уровней |
| **Система** | память, версия игры и патча, сейвы, нагрузка, список установленных перехватов |

Плюс:

- **Все DLC и робы** — включено: обходит сломанную проверку владения Steam (если DLC куплены, а игра их не видит).
- **Щит от крашей** — ошибки звука игры пишутся в журнал, игра продолжает работать.
- **Копия сейвов** при каждом сохранении (последние 15) — в `MagickaToolkit\save-backups`.
- **Разбор смерти на экране** — после смерти несколько секунд: кто и сколько снял, какая защита стояла.
- **Ограничение FPS** — свёрнутая игра не грузит видеокарту, в игре не больше 60 кадров.

Чего нет: авто-защиты, авто-лечения, щитов и куполов, техник и комбо, «Игрока» (бессмертие и пр.),
песочницы, арены, редактора испытаний.

## Установка

Самый простой способ — одна команда в PowerShell (находит игру, скачивает и распаковывает сама; если игра в
`Program Files`, попросит права администратора и перезапустится):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex (irm 'https://raw.githubusercontent.com/Elintirs/magicka-toolkit-lite/main/install.ps1')"
```

Вручную:

1. Закрой Magicka.
2. Скопируй папку **`MagickaToolkit`** из этого архива в папку игры — туда, где лежит `Magicka.exe`
   (обычно `C:\Program Files (x86)\Steam\steamapps\common\Magicka`).
3. В Steam: Magicka → Свойства → Параметры запуска:

   ```
   "C:\Program Files (x86)\Steam\steamapps\common\Magicka\MagickaToolkit\launch.exe" %command%
   ```

   (подставь свой путь). Либо просто запускай `launch.exe` из папки `MagickaToolkit` — он сам поднимет игру.
4. Запусти игру, нажми **F2** — откроется окно.

Журналы пишутся в `MagickaToolkit\logs` — если что-то не работает, там видно, что именно.

## Сборка из исходников

```
dotnet build src\Toolkit\Toolkit.csproj -c Release -p:Lite=true
```

`build\MagickaToolkit.Core.dll` — это и есть чистая сборка; положи её в `MagickaToolkit` рядом с
`launch.exe` (остальные файлы — загрузчик, Harmony и `magicka_boot.dll` — те же, что у полной версии).
